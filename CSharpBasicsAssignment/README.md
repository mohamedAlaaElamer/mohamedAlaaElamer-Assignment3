# C# Basics - Assignment 1: Console Apps, Types & Memory Model

This repository contains the solution for Module 1-1 Assignment, focusing on .NET project architecture, data types, memory semantics, and basic operators.

## 📁 Repository Structure

* `CSharpBasicsAssignment.csproj`: Project configuration file (.NET 8/9, Nullable, Implicit Usings enabled).
* `Program.cs`: Core application containing implementations for Parts A, B, C, D, and F.
* `Order.cs`: Class definition representing reference semantics and business calculations (Part C).
* `STACK_HEAP.md`: Visual markdown diagrams illustrating Stack vs. Heap allocation step-by-step (Part E).
* `ANSWERS.md`: Written responses to short-answer conceptual questions (Part G).
* `README.md`: Overview and running instructions.
